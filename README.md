# Erika Barker

**Quantitative research engineering · Machine learning · AI systems architecture**

I turn messy information into systems people can investigate and use. I design the architecture, direct the implementation and test whether the result holds up.

I'm the founder of Regime Analytics and a Quant Research Engineer at Mieza Research. Before this, I rebuilt commerce and data workflows for distressed private equity portfolio companies, taught graduate journalism and public relations, and served in Navy Combat Camera. The common thread is making sense of a difficult situation and building a useful way through it.

## Current work

### Hannah — persistent AI agents
My independent research into how memory and evolving internal state can shape attention, interests and long-term commitments. I architect a deployed, multi-agent system using Cloudflare Workers and Durable Objects, with semantic memory, background activity, inter-agent communication and routing across model providers. Behavioral experiments, deterministic replay and runtime traces let me evaluate how architectural choices affect behavior.

### Regime Analytics — machine learning for market research
Market-regime models, equity research and data pipelines. My work includes Gaussian hidden Markov models, PCA, clustering, random forests and gradient boosting. I evaluate models against persistence baselines using purged walk-forward validation and calibration checks. I also built and published a research dataset covering 3,910 US equities and 114 fields.

### Gov Intel and Mieza Terminal — economic intelligence
Gov Intel connects federal policy with public companies through government records, SEC disclosures, AI-assisted extraction and entity resolution, with source evidence people can inspect. At Mieza Research, I also built Mieza Terminal, adapting Regime Analytics into an interface for market regimes, sector rotation and statistical stock rankings.

The source for these current projects is private. Public code and writing are linked below.

## How I build

- Own the path from the research question through architecture, interface, evaluation and deployment.
- Use Python, TypeScript and SQL, with Cloudflare Workers, Durable Objects, D1, R2, KV and Vectorize.
- Direct OpenAI and Claude agents in VS Code, with independent review and checks against code and observed results.
- Build a working path early. Count operating cost, maintenance and people's attention as part of the design.
